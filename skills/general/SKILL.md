# 🏢 通用岗位 evidence skill / General Office Roles Evidence

> **适用岗位 / Applicable Roles**:**人事 HR / 行政 / 财务 / 销售 / 市场 / 运营 / 客服 / 法务 / 设计 / 教师 / 医护 / 公务员 / 传统行业非数字化岗**
> **HR / Admin / Finance / Sales / Marketing / Operations / Customer Service / Legal / Design / Teacher / Doctor / Civil Servant / Traditional non-digital roles**
>
> **共同特征 / Common Trait**:工作产物**部分数字化** + **大量纸质/沟通痕迹** → 证据更依赖**沟通留痕、人际互证、流程文书**。
> **Work products partially digital + heavy paper/communication traces** → evidence relies on **communication records, peer witnesses, process documents**.
>
> **关键差异 / Key Difference**:通用岗的核心证据在**审批单、合同、会议纪要、上级评价、同事证言**; 而非代码、监控。
> **Core evidence**: approval forms, contracts, meeting minutes, supervisor evaluations, peer testimony — not code or monitoring.
>
> **本 skill 重点 / Focus**:**保住邮件、文档、沟通** = 保住工作量和价值。
> **Preserve emails, documents, communications = preserve your contribution and value.**

## 0. 通用岗的"反讽陷阱"(必须先治)

| 心理 | 陷阱 | 治根 |
|------|------|------|
| "我天天坐办公室,老板看得见" | 锁号后才发现"系统里查不到我" | 个人日历 + 邮件 |
| "我的工作就是协调,没什么痕迹" | 恰恰相反,协调 = 大量邮件/会议 | 邮件自动归档 |
| "我是老员工,有信任" | 信任不等于证据,更不等于经济补偿 | 提前固化 |
| "公司没系统,我都是纸质的" | 反而强证据(签字版不可改) | 拍照/扫描 + 物管 |
| "我工作就是开会,没什么产出" | 会议本身就是产出 | 日历订阅 + 会议纪要 |

## 1. 通用岗的"五大证据领域"

### 领域 1:邮件 (最普适、最高效)

| # | 证据 | 取证方式 | 强度 | 雇主能删 |
|---|------|---------|------|---------|
| GEN-M1 | **公司邮箱全量** | Thunderbird / Outlook 拉 mbox | ★★★★★ | 强 |
| GEN-M2 | **个人邮箱 cc 备份** | 重要邮件 cc 个人邮箱 | ★★★★ | 强 |
| GEN-M3 | **自动转发到个人 Gmail** | 邮箱设置转发 | ★★★★ | 强 |
| GEN-M4 | **附件原文留底** | 关键附件下载 + 个人云 | ★★★★★ | 强 |
| GEN-M5 | **邮件 thread 截图** | 含发件人/时间/正文 | ★★★ | 弱(纸质) |
| GEN-M6 | **Outlook 邮件撤回** | 即使被撤,Outlook 有本地缓存 | ★★★★ | 弱 |
| GEN-M7 | **邮件签名档截图** | 显示职位/部门/电话 | ★★★★ | 弱(公网) |
| GEN-M8 | **外发邮件回执** | 邮件回执证明已送达 | ★★★★ | 弱(公网) |
| GEN-M9 | **日历邀请 (iCal)** | 邀请人 + 时间 + 主题 | ★★★ | 弱 |
| GEN-M10 | **邮件附件 PDF + 文件 hash** | 7-zip 加密压缩 | ★★★★★ | 不能 |

**反侦察**:
- 用个人邮箱 cc 重要邮件,但**不写机密**(避免泄密嫌疑)
- 自动转发用过滤器,**不转发工资条**等敏感信息
- 邮件截图要含"收件箱/发件箱"顶部信息,显示账号、时间

### 领域 2:审批 / 流程 / 文档 (中等强度,但**最稳定**)

| # | 证据 | 取证方式 | 强度 | 雇主能删 |
|---|------|---------|------|---------|
| GEN-P1 | **钉钉/飞书审批历史** | 设置 → 数据 → 导出 | ★★★★ | 强 |
| GEN-P2 | **OA 流程截图** | 含"已通过" + 审批人 + 时间 | ★★★★ | 强 |
| GEN-P3 | **电子合同 / 用印申请** | 个人邮箱抄送 | ★★★★★ | 强 |
| GEN-P4 | **报销单截图** | 钉钉/邮件抄送 | ★★★★ | 强 |
| GEN-P5 | **差旅申请** | 邮件抄送 | ★★★★ | 强 |
| GEN-P6 | **加班申请** | 邮件抄送 + 部门签字 | ★★★★★ | 强 |
| GEN-P7 | **请假申请** | 显示已批准,证明在岗 | ★★★★ | 强 |
| GEN-P8 | **签字版纸质文件** | 扫描或拍照 | ★★★★★ | 不能 |
| GEN-P9 | **印章/公章文件** | 拍照 + EXIF | ★★★★★ | 不能 |
| GEN-P10 | **文件分发登记表** | 自维护 spreadsheet | ★★★ | 强 |

**反侦察**:
- 所有审批通过后,立即**截图 + 抄送个人邮箱**
- 关键纸质文件,原件 + 复印件 + 扫描件 + 手机拍照,**4 份冗余**
- 用印文件自己留一份,贴日期贴纸

### 领域 3:沟通 / 会议 / 即时消息 (高强度,但要合规)

| # | 证据 | 取证方式 | 强度 | 雇主能删 |
|---|------|---------|------|---------|
| GEN-C1 | **微信工作群** | 迁移聊天记录到另一台设备 | ★★★★ | 强 |
| GEN-C2 | **钉钉工作群** | 备份到本地 | ★★★★ | 强 |
| GEN-C3 | **飞书工作群** | 导出功能 | ★★★★ | 强 |
| GEN-C4 | **企业微信聊天** | 迁移 + 截图 | ★★★★ | 强 |
| GEN-C5 | **电话录音** | 手机录音 + 通话记录截图 | ★★★ | 不能 |
| GEN-C6 | **面谈录音** | 录音笔,告知对方 | ★★★ | 不能 |
| GEN-C7 | **视频会议录屏** | 飞书/钉钉/腾讯会议 | ★★★ | 强 |
| GEN-C8 | **会议纪要** | 自写纪要 + 群内确认 | ★★★★ | 强 |
| GEN-C9 | **客户邮件** | 客户是第三方证人 | ★★★★★ | 弱 |
| GEN-C10 | **客户微信** | 注意脱敏,但保留"对话事实" | ★★★★ | 不能 |

**反侦察**:
- 录音前**告知对方**(部分省高院支持单方录音,但告知更稳妥)
- 视频会议时**确认本端也在录**,部分平台有"会议水印"防伪
- 与客户的邮件,不要把客户拉进自己纠纷

### 领域 4:纸面 / 物理 / 物管 (强证据,**最被忽视**)

| # | 证据 | 取证方式 | 强度 | 雇主能删 |

| GEN-PH3 | **快递签收单** | 自留底根 | ★★★ | 弱 |
| GEN-PH4 | **公司订阅杂志/收件人** | 杂志封页 | ★★★ | 弱 |
| GEN-PH5 | **同事合影** | 朋友圈/相册 | ★★★ | 弱 |
| GEN-PH6 | **公司内部活动照片** | 含你入镜 | ★★★ | 弱 |

**反侦察**:

## 2. 不同子岗位的"专属证据"

### 2.1 人事 HR 岗

| 维度 | 重点证据 | 暗坑 |
|------|---------|------|
| **招聘** | 候选人简历、面试记录 | 涉及候选人隐私,合规留底 |
| **入职** | 劳动合同、Offer、背景调查 | 自己用印的也拍照 |
| **离职** | 离职面谈记录、解除通知 | ⚠️ 自相矛盾,容易被反咬"是你经手的" |
| **薪资** | 个税申报、社保公积金 | 截图留底 |
| **考勤** | 加班申请、请假单 | 重要批准截图 |
| **绩效** | 360 评估、KPI | 自维护绩效档案 |
| **培训** | 培训记录、签到 | 推个人邮箱 |

**关键反讽**:HR 自己被裁时,容易有"我把员工裁了,现在轮到我"的反噬,**所有流程自留证据**。

### 2.2 行政岗

| 维度 | 重点证据 |
|------|---------|
| **采购** | 采购单、合同、付款记录 |
| **资产** | 资产登记表、领用记录 |
| **会议** | 会议纪要、会议室预定 |
| **接待** | 接待清单、礼品签收 |
| **车辆** | 用车记录、油费报销 |
| **差旅** | 行程单、酒店发票 |
| **后勤** | 维修、清洁、安保 |

**关键证据**:所有**签字 + 盖章文件**自留副本。

### 2.3 销售岗

| 维度 | 重点证据 | 暗坑 |
|------|---------|------|
| **客户开发** | 名片、CRM 截图 | ⚠️ 客户名单可能涉商业秘密 |
| **合同** | 销售合同、回款记录 | 客户邮箱是第三方证人 |
| **业绩** | 业绩报表、回款截图 | 截图+ 邮件抄送 |
| **出差** | 行程单、报销 | 高频出差,价值更高 |
| **佣金** | 提成计算、发放记录 | 自维护销售台账 |
| **招投标** | 标书、过程文档 | 多人合作,自留过程记录 |

### 2.4 财务岗

| 维度 | 重点证据 | 暗坑 |
|------|---------|------|
| **凭证** | 记账凭证、原始单据 | **不带走**,只自留复印件 |
| **报表** | 月度/季度/年度报表 | 自维护脱敏版 |
| **审计** | 审计报告、调整分录 | 自维护副本 |
| **税务** | 申报表、缴款书 | 部分可对外查询 |
| **银行** | 回单、对账单 | 截图+ 脱敏 |
| **OA** | 报销审批 | 同审批类证据 |

**关键**:财务是"高敏感"岗,取证要注意"**不带走公司财务资料**",只拍照/复印/截图。

### 2.5 法务岗

| 维度 | 重点证据 |
|------|---------|
| **合同审查** | 审批意见、修改痕迹 |
| **诉讼** | 起诉状、答辩状、判决书 |
| **合规** | 合规检查报告 |
| **知识产权** | 商标、专利申请 |
| **案件台账** | 自维护案件 spreadsheet |
| **外聘律师** | 邮件往来 |

**反讽**:法务被裁时反而**最有证据能力**,因为天天处理证据问题。

### 2.6 客服 / 运营岗

| 维度 | 重点证据 |
|------|---------|
| **客户咨询** | 邮件、聊天记录 |
| **客户评价** | 工单截图、NPS 评分 |
| **运营活动** | 活动方案、效果数据 |
| **值班** | 排班表、响应记录 |
| **培训** | 培训记录、考试 |
| **绩效** | KPI 报表 |

### 2.7 教师 / 医护 / 公务员

| 维度 | 重点证据 |
|------|---------|
| **教学/诊疗** | 课件、处方、文件 |
| **排课/排班** | 课表/班表 |
| **评价** | 学生评价、患者反馈 |
| **培训** | 继续教育证明 |
| **论文/案例** | 公开刊物、案例库 |
| **第三方** | 学校/医院红头文件 |

**公务员特殊**:可以走**劳动监察**和**纪检监察双轨**。
